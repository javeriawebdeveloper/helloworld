# Hello World Practice

## Project goal

Learn Git and GitHub by building a simple web page that displays "Hello, World!".
Practice working on branches, reviewing changes, making commits, and pushing
those commits to a private GitHub repository.

## Open the page locally on Windows

1. On GitHub, select the `develop` branch, then choose **Code > Download ZIP**.
2. In File Explorer, right-click the downloaded ZIP and choose **Extract All**.
3. Open the extracted folder. Keep `index.html` and `styles.css` together.
4. Double-click `index.html` to open it in your web browser. If needed,
   right-click it and choose **Open with > Microsoft Edge** or **Google Chrome**.
5. You should see a centered blue "Hello, World!" heading on a pale blue background.

If you already have this repository on your Windows computer, open Git Bash in
its folder and run `git switch develop`, then `git pull`. Follow steps 3–5 above.

No installation or local web server is needed. After saving changes to the HTML
or CSS, refresh the browser to see them.
